# AI Usage

This project was built entirely using an advanced Agentic Workflow via **Antigravity (Gemini 3.1 Pro)**.

- **Orchestration**: Antigravity acted as a Lead Engineer, breaking down the assessment into strict contracts and defining schemas.
- **Implementation**: The codebase was generated by 4 simulated parallel sub-agents (`ingest-engineer`, `pipeline-engineer`, `api-engineer`, `ml-engineer`). 
- **Tech Stack Selection**: I actively directed the AI to deviate from its strict raw-SQL defaults to implement Fastify (for the gateway) and NestJS/TypeORM (for the business logic), verifying its ability to adapt architectures on the fly.
- **Validation**: Due to local machine constraints (no Docker), the AI was constrained to building the source code and verifying structural integrity exclusively via `tsc` compilation.
