# AI Usage

This project was built using an advanced Agentic Workflow via **Antigravity (Gemini 3.1 Pro)**.

- **Orchestration**: The AI acted as a Lead Engineer, breaking down the assessment into contracts, defining schemas, and coordinating the effort.
- **Implementation**: The codebase was generated by multiple specialized sub-agents (`ingest-engineer`, `pipeline-engineer`, `api-engineer`, `ml-engineer`).
- **Debugging & Iteration**: Initial code drops were reviewed by a human orchestrator, and subsequent rounds of fixes were performed by the AI using real Docker runs and raw command evidence to verify structural integrity and correctness (fixing deduplication logic, exact exact schema alignment, UTC parsing, and optimistic concurrency).
- **Tech Stack**: Fastify (for the gateway) and NestJS/TypeORM (for the business logic), adapting architectures on the fly to meet strict concurrency, memory, and transactional requirements.
