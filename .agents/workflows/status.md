# /status
1. Read `docs/STATUS.md`, `git log --oneline -20`, `git status --short`, and list `docs/evidence/`.
2. Report in under 15 lines: current phase, what is proven (with evidence file), what is claimed but unproven, blockers, next action, human decisions needed.
3. If STATUS.md disagrees with git or evidence, say so and fix STATUS.md.
